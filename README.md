# 🚀 First Blood - AI Telegram Bot

Welcome to **First Blood**, my first fully functional Telegram bot built using the **aiogram 3** framework and Python. I designed and deployed this entire project from scratch directly using my iPhone!

## 🎓 Project Purpose & Motivation
This bot is a personal milestone on my journey to getting into top universities in the US (such as **Stanford, Berkeley, and Wharton**). 
Inside the bot, you will find interactive buttons, including my personal manifesto:
> *"Get into the best university in the US or another country that is just as strong and smart, believe in yourself as much as I believe in you."*

## 🛠️ Tech Stack & Features
- **Language:** Python 3
- **Framework:** aiogram 3 (Asynchronous Telegram Bot API)
- **Deployment:** Cloud hosting via Replit
- **Security:** Secret environment variables for `TELEGRAM_BOT_TOKEN` protection
